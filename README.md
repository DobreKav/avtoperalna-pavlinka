# Автоперална Павлинка

Систем со картички за самоуслужен бокс со пена и вода.

```
[картичка] → [PC/SC читач] --USB--> [лаптоп: PeralnaAgent.exe + админ панел] --LAN / Modbus TCP--> [Siemens S7-1200] → пена / вода
```

- Картичката се става во читачот и **останува таму**. Додека е внатре, боксот работи и се наплаќа по минута (стандардно 20 ден/мин).
- Кога картичката ќе се извади, боксот застанува и перењето се запишува во базата.
- Ако парите на картичката се потрошат, боксот застанува и тогаш кога картичката е сè уште внатре.
- Лаптопот е **сервер**. PLC-то е **клиент**: тоа ги чита регистрите од лаптопот.

## Инсталација

1. Стартувај `AvtoperalnaPavlinka-Setup.exe` и потврди „Yes“ (бара администратор).
2. Изберете папка (стандардно `C:\AvtoperalnaPavlinka`) → **Инсталирај**. Инсталацијата:
   - ги копира програмата, вградениот PHP и базата (SQLite). Не треба XAMPP ниту MySQL.
   - прави икони на Desktop и во Start менито и го стартува агентот кога ќе се вклучи компјутерот.
   - отвора порта 502 во Windows Firewall за PLC-то.
3. Се отвора админ панелот <http://localhost:8080/>. Прв пат направи админ корисник.
4. Приклучи го читачот (ACR122U, ACR1252 или друг PC/SC читач).
5. Лаптопот треба да има **фиксна IP адреса** кон PLC-то, на пример `192.168.1.10`.

Повторно пуштање на Setup.exe ја **ажурира** програмата. Базата (`data\peralna.sqlite`), `agent.ini` и `app\config.php` остануваат.
Деинсталација: Start мени → Автоперална Павлинка → Деинсталирај, или Settings → Apps. Базата останува.

**Бекап:** копирај ја папката `data\` (особено `peralna.sqlite`) на USB редовно. Во неа се сите картички и пари.

## Секојдневна работа

- **Нова картичка:** стави ја во читачот. На почетната страница се појавува „Непозната картичка … **Регистрирај ја**“.
- **Полнење:** Картички → картичката → +100 / +200 / +500 / +1000 или друг износ.
- **Цена:** страница **Цени**. Промената важи за следното ставање картичка.
- На почетната страница е статусот на **Агент**, **Читач на картички** и **PLC**, со зелено или црвено светло.

## Siemens S7-1200 (пена и вода)

Готовата програма е во `plc\FB_Peralna.scl`.

1. TIA Portal → PLC → **External source files** → Add new external file → `FB_Peralna.scl` → десен клик → **Generate blocks from source**.
2. Во `FB_Peralna` смени ја IP адресата на лаптопот (4-те `ADDR` линии, стандардно `192.168.1.10`). Провери го `InterfaceId`: тоа е Hardware identifier на PROFINET интерфејсот, обично 64.
3. Повикај го во OB1 со копчињата ПЕНА / ВОДА / СТОП и излезите за пумпата/вентилите (примерот е на дното на фајлот).
4. PLC-то и лаптопот мора да се во иста мрежа, на пример PLC `192.168.1.20` и лаптоп `192.168.1.10`, маска 255.255.255.0.

Однесување:
- ПЕНА и ВОДА работат само додека картичката е во читачот и има пари.
- СТОП ја паузира пената или водата, но времето се наплаќа сè додека картичката не се извади.
- **Watchdog:** ако лаптопот не се јави 5 секунди, двата излеза се гасат.

## Modbus TCP мапа

Лаптопот е Modbus TCP сервер на порта 502. Адресите почнуваат од 0 (40001 = регистар 0).

| Holding register | Значење |
|---|---|
| **0** | **ENABLE**: 1 = смее да работи, 0 = стоп. Истото е и coil 0. |
| 1 | Уште колку секунди има на картичката |
| 2 | Салдо на картичката, во денари |
| 3 | Наплатено во ова перење |
| 4 | Статус: 0 нема картичка · 1 работи · 2 парите се потрошени · 3 нема доволно пари · 4 непозната картичка · 5 блокирана · 6 серверска грешка · 7 нема читач · 8 грешка при читање |
| **5** | **HEARTBEAT**: +1 секоја секунда |
| 6 | Уште колку минути има на картичката |
| 10–19 | Слободни. PLC-то може да запишува тука. |

## Поставки на агентот (`agent.ini`)

| | |
|---|---|
| `machine` | Код на боксот од страницата Цени (`B1`) |
| `web_port` | Порта на админ панелот (8080) |
| `web_bind` | `127.0.0.1` = панелот е достапен само од лаптопот; `0.0.0.0` = и од телефон на истата мрежа |
| `modbus_port` | Порта за PLC-то (502) |
| `tick_seconds` | На колку секунди агентот му јавува на серверот (15) |
| `offline_stop_seconds` | Се гаси ако серверот не одговара толку секунди (45) |
| `simulate` | `1` = тест без читач. Во прозорецот на агентот пишувај `in 04A1B2C3` / `out`. |

## Како се наплаќа

- Цената по минута се наплаќа во секунда, заокружено нагоре на цел денар.
- Ако агентот престане да се јавува 2 минути, серверот го затвора перењето и наплаќа само до последното јавување.
- Во `transactions` се запишува по еден ред за секое полнење, корекција и перење.
