# Автоперална Павлинка

Систем со картички за самоуслужен бокс со пена и вода.

```
[картичка] → [PC/SC читач] --USB--> [лаптоп: PeralnaAgent.exe + админ панел] --LAN / Modbus TCP--> [Siemens S7-1200] → пена / вода
```

- Картичката се става во читачот и **останува таму**. Додека е внатре, боксот работи и се наплаќа по минута (стандардно 20 ден/мин).
- Кога картичката ќе се извади, боксот застанува и перењето се запишува во базата.
- Ако парите на картичката се потрошат, боксот застанува и тогаш кога картичката е сè уште внатре.
- Врската со PLC-то е **Modbus TCP**. IP адресите и портите се внесуваат рачно во админ панелот, страница **PLC врска**. Агентот ги применува за неколку секунди, без рестарт. Има два режима:
  - **Лаптопот е сервер:** PLC-то се поврзува на лаптопот (MB_CLIENT, `plc\FB_Peralna.scl`).
  - **PLC-то е сервер:** лаптопот се поврзува на PLC-то (MB_SERVER, `plc\FB_Peralna_Server.scl`). Во PLC програмата не се пишува ништо за лаптопот.

## Инсталација

1. Стартувај `AvtoperalnaPavlinka-Setup.exe` и потврди „Yes“ (бара администратор).
2. Изберете папка (стандардно `C:\AvtoperalnaPavlinka`) → **Инсталирај**. Инсталацијата:
   - ги копира програмата, вградениот PHP и базата (SQLite). Не треба XAMPP ниту MySQL.
   - прави икони на Desktop и во Start менито и го стартува агентот кога ќе се вклучи компјутерот.
   - дозволува агентот во Windows Firewall (за било која порта избрана во PLC врска).
   - **Тест додатоци (емулатори)** се исклучени по default. За вистинска перална остави ги исклучени. При ажурирање без нив, старите емулатори се бришат.
3. Се отвора админ панелот <http://localhost:8080/>. Прв пат направи админ корисник.
4. Приклучи го читачот (ACR122U, ACR1252 или друг PC/SC читач).
5. Лаптопот треба да има **фиксна IP адреса** кон PLC-то, на пример `192.168.1.10`.

Повторно пуштање на Setup.exe ја **ажурира** програмата. Базата (`data\peralna.sqlite`), `agent.ini` и `app\config.php` остануваат.
Деинсталација: Start мени → Автоперална Павлинка → Деинсталирај, или Settings → Apps. Базата останува.

**Бекап:** копирај ја папката `data\` (особено `peralna.sqlite`) на USB редовно. Во неа се сите картички и пари.

## Поставување во перална (без емулатори)

1. Инсталирај **без** „Тест додатоци“.
2. Лаптопот и PLC-то во иста мрежа, со фиксни адреси, на пример лаптоп `192.168.1.10`, PLC `192.168.1.20`, маска `255.255.255.0`.
3. Админ панел → **PLC врска**, избери режим и внеси ги адресите:

| Режим | Во админ панелот | Во TIA Portal |
|---|---|---|
| **PLC-то е сервер** (препорачано) | IP на PLC-то (`192.168.1.20`), порта (`502`), Unit ID (`1`), освежување (`200` ms) | `FB_Peralna_Server.scl`; `LocalPort` = истата порта. IP на PLC-то во Device configuration. |
| **Лаптопот е сервер** | IP на која слуша лаптопот (`0.0.0.0` = сите), порта (`502`), опционално дозволена IP на PLC-то | `FB_Peralna.scl`; IP адресата на лаптопот во 4-те `ADDR` линии, портата во `RemotePort`. |

4. На врвот на страницата се гледа во живо дали PLC-то е поврзано. Ако не е, пишува и зошто, на пример „PLC-то не одговара (провери кабел, IP адреса и маска)“ или „PLC-то не слуша на таа порта“.
5. **Тест режим** нека остане исклучен. Тогаш виртуелниот читач е затворен и демо картичката `DEMO0001` се одбива.

## Додатоци за тест (без хардвер)

Само ако при инсталација е штиклирано „Тест додатоци“ и во админ панелот е вклучен **Тест режим**. Емулаторот на PLC работи само во режимот „Лаптопот е сервер“.

Во Start менито и на Desktop има два додатока:

- **Емулатор — читач на картички** (`CardEmulator.exe`). Додека работи, светлото „Читач на картички“ во админ панелот е зелено. Внеси број на картичка (на пример `TEST0001`) и кликни **Стави картичка во читачот** или **Извади картичка**. Непозната картичка се регистрира од админ панелот („Регистрирај ја“).
- **Емулатор — PLC S7-1200** (`PlcEmulator.exe`). Се поврзува со агентот преку Modbus исто како вистинското PLC, па светлото „PLC“ станува зелено. Покажува:
  - екран на допир со името на картичката, секундите, салдото и копчињата ПЕНА / ВОДА / СТОП
  - трите физички копчиња (I0.0–I0.2)
  - излезите Q0.0 пена и Q0.1 вода
  - дигиталниот секундарник (QW2, BCD)

  Логиката е иста како во `plc\FB_Peralna.scl`.

Со двата додатока може да се тестира целото перење: картичката влегува, се наплаќа по минута, се бира пена или вода, картичката се вади.

## Секојдневна работа

- **Нова картичка:** стави ја во читачот. На почетната страница се појавува „Непозната картичка … **Регистрирај ја**“.
- **Полнење:** Картички → картичката → +100 / +200 / +500 / +1000 или друг износ.
- **Цена:** страница **Цени**. Промената важи за следното ставање картичка.
- На почетната страница е статусот на **Агент**, **Читач на картички** и **PLC**, со зелено или црвено светло.

## Siemens S7-1200 (пена и вода)

Има две готови програми, по една за секој режим од страницата **PLC врска**:
- `plc\FB_Peralna_Server.scl`: PLC-то е Modbus сервер (MB_SERVER). Не треба IP на лаптопот; портата е `LocalPort` (502). MB_SERVER V5+ (TIA V15+), инаку Regs оди во глобален DB без „Optimized block access“.
- `plc\FB_Peralna.scl`: PLC-то е клиент (MB_CLIENT) и се поврзува на лаптопот. Упатството подолу е за неа.

И двете ја имаат истата логика на боксот, истите влезови и излези и истите полиња за екранот на допир.

1. TIA Portal → PLC → **External source files** → Add new external file → `FB_Peralna.scl` → десен клик → **Generate blocks from source**.
2. Во `FB_Peralna` смени ја IP адресата на лаптопот (4-те `ADDR` линии, стандардно `192.168.1.10`). Провери го `InterfaceId`: тоа е Hardware identifier на PROFINET интерфејсот, обично 64.
3. Повикај го во OB1 со копчињата ПЕНА / ВОДА / СТОП, излезите за пумпата/вентилите и `SecondsBCD` за дигиталниот секундарник (примерот е на дното на фајлот).
4. **Екран на допир (WinCC, на пример KTP700 Basic):** во `FB_Peralna_DB` се наоѓаат:
   - `CardName` (име), `SecondsLeft`, `MinutesLeft`, `SecondsPart` (за mm:ss), `Balance`
   - `Status`, со текстуална листа (текстовите се во коментарот на врвот на фајлот)
   - копчињата на екранот, кои пишуваат во `HmiFoam` / `HmiWater` / `HmiStop` (Press → SetBit, Release → ResetBit)
5. PLC-то и лаптопот мора да се во иста мрежа, на пример PLC `192.168.1.20` и лаптоп `192.168.1.10`, маска 255.255.255.0.

Однесување:
- ПЕНА и ВОДА работат само додека картичката е во читачот и има пари.
- **Се наплаќа само додека тече ПЕНА или ВОДА.** СТОП ги запира и водата и трошењето пари. По ставањето на картичката не се наплаќа ништо сè додека не се избере ПЕНА или ВОДА.
- **Watchdog:** ако лаптопот не се јави 5 секунди, двата излеза се гасат.

## Modbus TCP мапа

Иста е во двата режима. Адресите почнуваат од 0 (40001 = регистар 0). Кога PLC-то е сервер, лаптопот на секои 200 ms (може да се смени) ги запишува регистрите 0–9 и 20–52 (FC16) и ги чита 10–19 (FC3). Регистрите 10–19 не ги пишува никогаш.

| Holding register | Значење |
|---|---|
| **0** | **ENABLE**: 1 = смее да работи, 0 = стоп. Истото е и coil 0. |
| 1 | Уште колку секунди има на картичката |
| 2 | Салдо на картичката, во денари |
| 3 | Наплатено во ова перење |
| 4 | Статус: 0 нема картичка · 1 работи · 2 парите се потрошени · 3 нема доволно пари · 4 непозната картичка · 5 блокирана · 6 серверска грешка · 7 нема читач · 8 грешка при читање |
| **5** | **HEARTBEAT**: +1 секоја секунда |
| 6 | Уште колку минути има на картичката |
| 10 | **Го пишува PLC-то:** програма 0 СТОП, 1 ПЕНА, 2 ВОДА. Картичката се наплаќа само кога е 1 или 2. |
| 11–19 | Слободни. PLC-то може да запишува тука. |
| 20 | Должина на името на картичката (знаци, до 32) |
| 21–52 | Име на картичката: по еден UTF-16 знак во регистар. Кирилица работи; во PLC-то е `WString`. |

## Поставки на агентот (`agent.ini`)

| | |
|---|---|
| `machine` | Код на боксот од страницата Цени (`B1`) |
| `web_port` | Порта на админ панелот (8080) |
| `web_bind` | `127.0.0.1` = панелот е достапен само од лаптопот; `0.0.0.0` = и од телефон на истата мрежа |
| `modbus_port`, `plc_mode`, `plc_ip`, `plc_port` | Само почетна вредност. Вистинските поставки се во админ панелот → **PLC врска**. При прв старт по ажурирање, панелот ги презема од тука. |
| `virtual_reader_port` | Порта за додатокот „Емулатор — читач на картички“ (5021, само од овој компјутер). Се отвора само во **Тест режим**. |
| `tick_seconds` | На колку секунди агентот му јавува на серверот (15) |
| `offline_stop_seconds` | Се гаси ако серверот не одговара толку секунди (45) |
| `simulate` | `1` = тест без читач. Во прозорецот на агентот пишувај `in 04A1B2C3` / `out`. |

## Како се наплаќа

- Цената по минута се наплаќа во секунда, заокружено нагоре на цел денар, **само додека тече пена или вода**.
- Ако агентот престане да се јавува 2 минути, серверот го затвора перењето и наплаќа само до последното јавување.
- Во `transactions` се запишува по еден ред за секое полнење, корекција и перење.
